# 💡 Never Bored

A responsive React application that helps users discover new activities and make the most of their free time.

## ✨ Features

- Random activity suggestions
- Generate a new activity with one click
- Activity categories
- Number of participants
- Estimated budget
- Loading and error handling
- Modern and responsive design

## 🛠️ Technologies

- React
- Vite
- JavaScript
- HTML5
- CSS3
- Bored API
- Google Fonts

## ⚛️ React Concepts

- Functional components
- useState
- useEffect
- Dependency array
- Conditional rendering
- Event handling
- Async/await
- Fetch API

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/LeahLogic/never-bored.git
```

Install dependencies:

```bash
cd never-bored
npm install
```

Start the development server:

```bash
npm run dev
```

## 📚 API

Activity suggestions are provided by [Bored API — Le Wagon](https://bored.api.lewagon.com/).
